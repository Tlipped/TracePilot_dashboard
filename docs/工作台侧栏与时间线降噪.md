# 工作台侧栏与时间线降噪

## 问题

- 右侧智能体摘要长期占用固定宽度，结构化报告和日志工作区偏窄。
- `CONNECTED`、`PING`、`PONG` 等连接维护事件进入智能体时间线后，没有用户可读内容，只显示“系统事件 / 暂无预览内容”。
- 模型补丁中的 `>>>>>>> REPLACE` 等控制标记偶尔落在 Markdown 代码块外，被误解析成多层引用，形成一排无语义箭头。

## 实现

1. 右侧详情栏增加收起/展开控制。收起后仅保留 44px 的“展开详情”入口，主分析区自动获得剩余宽度。
2. 折叠状态写入浏览器本地存储，同一浏览器下刷新任务页面后继续沿用。
3. 时间线过滤连接维护事件和无标题、无正文的控制事件；有效进度、检查点、任务状态和异常事件继续保留。
4. Markdown 统一渲染入口识别代码块外的补丁控制标记，将其显示为普通代码文本，避免被解析成多层引用；代码块内原始补丁内容保持不变。

## 回归约束

`npm run test:smoke` 对侧栏入口、时间线过滤和 Markdown 控制标记归一化做静态契约检查；`npm run build` 负责 TypeScript 和生产构建检查。
